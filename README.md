Entry for [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) on Make.fun — one funny single-line one-star review from a house cat about its human.

> One star. He moved my box to make room for his 'standing desk', then stood on it himself for six minutes and called it exercise.

The program (`main.ts`, Node 22, no dependencies) writes that single line to `/output/entry.txt` — 128 characters, one line, no trailing newline. It runs fully offline: only `node:fs`, no network, no randomness, no clock.

## Run

```sh
node main.ts
cat /output/entry.txt
```
